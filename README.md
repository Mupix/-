# PriceTracker (Phase1)

このリポジトリは Windows ローカルで動作する「商品価格追跡 Web アプリ」の実装です。Phase1 ではプロジェクト骨組み・FastAPI・SQLite・基本 UI を実装しています。

## 1. 必要なもの
- Windows 10/11
- Python 3.12+
- 推奨: PowerShell / cmd

## 2. Python の確認
コマンドプロンプトで以下を実行して Python バージョンを確認してください:
```
python --version
```

## 3. 初回セットアップ
リポジトリルートで `setup.bat` を実行してください（仮想環境作成とライブラリのインストールを行います）:
```
setup.bat
```

セットアップは以下を行います:
- `.venv` 仮想環境の作成
- `requirements.txt` のインストール
- `database/` ディレクトリ作成

## 4. 起動方法
セットアップ後、`start.bat` をダブルクリック、またはコマンドプロンプトから実行してください:
```
start.bat
```
自動で uvicorn が起動し、ブラウザで `http://localhost:8000` が開きます。

## 5. 停止方法
- Uvicorn を起動したコンソールを閉じる、または Ctrl+C を押してください。

## 6. 楽天APIキーの設定方法
Phase1 ではまだ楽天API による取得は有効化していません。将来的に `RAKUTEN_APPLICATION_ID` などを `.env` や環境変数から読み込める設計にします。

## 7. 商品の追加方法
- トップページ右上の「＋」ボタンから追加できます。
- 必須: 商品名、商品URL。ショップは自動判定されます（判定できない場合は「その他」）。

## 8. Excel/CSV 出力方法
Phase1 では未実装です。Phase8 で実装予定です。

## 9. 価格取得の仕組み（概要）
価格取得やスケジューラは Phase1 では未実装（スタブ）。将来的に `scrapers/` に Fetcher を追加し、APScheduler で定期取得を行います。

## 10. トラブルシューティング
- Python が見つからない場合は https://www.python.org/ からインストールしてください。
- 依存関係が不足している場合は `setup.bat` を再実行してください。
